Computerspil System

Gruppe: The Boys
Gruppemedlemmer: Anwar, Najib

**Hvad programmet gør**

Programmet er et system til at administrere computerspil og spillere. Det kan tilføje spil og spillere, opdatere scores, beregne samlet indtjening fra spil og finde topscoreren.


**Vores opbygning**

Game: Gemmer spildata som ID, titel, genre og pris

Player: Gemmer spillerdata som ID, navn, alder og score

GameSystem: Styrer arrays af spil og spillere samt søgning og beregninger


**Vores udvidelse**

Vi har tilføjet funktioner til at beregne den samlede indtjening for alle spil samt finde spilleren med den højeste score.


**Noget vi syntes var svært**

At holde styr på tællerne gameCount og playerCount i vores arrays samt at hente objekter ud via deres ID med søgeløkker.
